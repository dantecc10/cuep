# 2. Para coordinadores: organizar mejor las asesorías

## ¿Qué problema resuelve para la coordinación?

La coordinación suele concentrar información dispersa: disponibilidades,
materias, grupos, sedes, cambios de última hora y seguimiento de acuerdos. CUEP
propone reunir esa información en un solo lugar y usarla para construir
propuestas de horario.

Esto permite reducir el trabajo de copiar, revisar y corregir horarios
manualmente. También deja un registro de las propuestas anteriores para que las
decisiones puedan explicarse y recuperarse.

## Flujo de trabajo propuesto

### 1. Preparar la oferta

Se registran las materias, el nivel educativo, las horas necesarias y los
grupos que se abrirán en cada sede.

### 2. Integrar al equipo de tutores

Por cada tutor se registra, con su consentimiento y de forma actualizada:

- información básica de contacto;
- materias que puede acompañar;
- preferencias entre materias;
- días y horarios disponibles;
- carga máxima que desea asumir.

### 3. Solicitar una propuesta

La coordinación selecciona la sede y los grupos que desea organizar. CUEP
revisa las combinaciones posibles y genera una propuesta.

### 4. Revisar antes de publicar

La coordinación verifica que la propuesta tenga sentido para la comunidad:

- que los horarios sean accesibles;
- que las cargas sean razonables;
- que se respete la continuidad de los grupos;
- que se atiendan situaciones de cuidado, traslado o accesibilidad;
- que ningún criterio técnico contradiga un acuerdo colectivo.

### 5. Comunicar y actualizar

Una vez acordado el horario, se comparte con tutores y estudiantes. Si cambia
una disponibilidad o un grupo, puede generarse una nueva propuesta sin perder
el historial de la anterior.

## Beneficios para la coordinación

- Menos tiempo dedicado a tareas repetitivas.
- Menos errores y traslapes.
- Mayor visibilidad de las necesidades que no se están cubriendo.
- Comparación entre propuestas antes de tomar una decisión.
- Registro de cambios y acuerdos.
- Mejor distribución de la carga entre quienes participan.

## Responsabilidades que no desaparecen

La herramienta no reemplaza la coordinación. El equipo coordinador debe
validar la información, escuchar a las personas involucradas, resolver
excepciones y decidir qué propuesta es adecuada. Una propuesta técnicamente
posible puede no ser pedagógica, accesible o políticamente conveniente.

## Estado actual

La documentación técnica define este flujo y ya existe una base de backend,
frontend y un trabajador local para el cálculo. La interfaz y las funciones
completas siguen desarrollándose; por eso la disponibilidad de cada pantalla
debe confirmarse con el equipo responsable antes de planear su uso cotidiano.
