# 6. Beneficios, cuidados y límites

## Beneficios que se buscan

| Área | Beneficio esperado |
|---|---|
| Organización | Una visión común de grupos, materias, tutores y horarios. |
| Tiempo | Menos horas invertidas en cuadrar manualmente las agendas. |
| Calidad | Menos traslapes y más continuidad en las asesorías. |
| Cuidado | Cargas de trabajo más visibles y discutibles. |
| Transparencia | Historial de propuestas y criterios de asignación. |
| Autonomía | Uso de software libre y posibilidad de mantener el sistema. |
| Aprendizaje | Datos y experiencias para mejorar la planeación de futuras sedes. |

## Límites importantes

### Un sistema no crea recursos

Si no hay suficientes tutores, aulas, tiempo o equipos, el sistema no puede
inventarlos. Puede mostrar que existe una necesidad sin atender, lo que ayuda a
organizar una respuesta, pero no la resuelve por sí mismo.

### La mejor solución no siempre es la de mayor puntuación

El motor puede priorizar preferencias, continuidad o equilibrio de cargas según
reglas definidas. Esas reglas son una ayuda, no una medida absoluta de justicia.
La coordinación debe revisar el resultado y explicar cualquier cambio.

### Los datos pueden estar equivocados

Una disponibilidad desactualizada o una materia mal registrada produce una mala
propuesta. La revisión de datos es una responsabilidad permanente.

### La tecnología tiene costos

Aunque el proyecto busca usar software libre, requiere equipos, conexión,
mantenimiento, capacitación y personas responsables. Estos recursos deben
considerarse desde la planeación.

## Principios de uso responsable

1. Participación informada: explicar qué datos se solicitan y para qué.
2. Proporcionalidad: pedir solo la información necesaria.
3. Revisión humana: no publicar una asignación sin validarla.
4. Derecho a corregir: permitir actualizar datos y señalar errores.
5. No sanción: no convertir los datos en mecanismos de vigilancia.
6. Accesibilidad: considerar las condiciones reales de cada comunidad.
7. Evaluación: revisar si los beneficios prometidos se cumplen.

## Cómo evaluar si funciona

Además de medir el tiempo técnico, conviene preguntar:

- ¿Se redujeron los traslapes y cancelaciones?
- ¿La carga está mejor distribuida?
- ¿Los tutores consideran viables sus horarios?
- ¿Los grupos reciben las materias que necesitan?
- ¿La coordinación puede explicar cómo se llegó a una propuesta?
- ¿La herramienta ahorra trabajo sin quitar capacidad de decisión?
